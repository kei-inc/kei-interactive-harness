# Context

Where the intent lives. This is not a specification and nothing here is locked.
It is a map of what we are building, why, and where to look, so the agent starts
each session with the same picture I have rather than reconstructing it from the
code.

Update it when the picture changes. Leave sections empty rather than deleting
them, so it is obvious what has not been decided yet.

Two or three sentences. Who it is for and what it does for them.
